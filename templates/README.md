# Agentik Studio — legal document templates

The current site has **one studio homepage** and **separate game pages**.

- Cozy Cafe: `https://agentik2020.github.io/cozycafe-legal/privacy/` and `.../terms/`
- Arrows: Ghost Puzzle: `https://agentik2020.github.io/cozycafe-legal/ghost-arrows/privacy/` and `.../terms/`
- New games can use a new folder such as `new-game/privacy/index.html` and `new-game/terms/index.html`; use the game's own exact URLs on its detail page.

Start with `privacy-policy.template.md` and `terms-of-use.template.md`, fill in the real app's SDKs, data practices, pricing, policies, then publish checked HTML. Do not publish an unfilled template or blindly copy another game's policy. Verify current disclosures for **Arrows: Ghost Puzzle** before its release, because the existing policy may have been drafted from another game.

These templates are internal drafting aids, not legal advice. They are not linked publicly from the studio website.
